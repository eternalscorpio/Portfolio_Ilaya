07 — Performance Strategy

SPEED + QUALITY

Heavy animation stacks can destroy UX. These strategies ensure cinematic visuals with production-grade performance.

60
FPS Target — Locked 60fps
Three.js RAF loop uses delta time. All CSS animations use transform/opacity only (GPU composited). No layout-triggering properties animated.
90
Lighthouse Performance Score Target
Three.js loaded lazily after LCP. Anime.js tree-shaken. GSAP plugins imported individually. Hero canvas only renders in viewport. Off-screen objects paused.
3D
WebGL Optimization Strategy
BufferGeometry over Geometry. Single PointsMaterial for all particles. Frustum culling enabled. Dispose renderer on component unmount. Pixel ratio capped at 2.
A11
Accessibility + Reduced Motion
@media (prefers-reduced-motion: reduce) disables all parallax and entrance animations. Canvas replaced with static gradient. All animations respect OS preference.
// Three.js Performance Setup — Hero Canvas const renderer = new THREE.WebGLRenderer({ canvas: heroCanvas, antialias: false, // OFF on mobile for perf powerPreference: 'high-performance', alpha: true }); renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2)); // Lazy load Three.js after hero LCP const loadThree = async () => { const { initHeroScene } = await import('./hero3d.js'); initHeroScene(renderer); }; window.addEventListener('load', loadThree);
// Anime.js — Section Entrance (Scroll Triggered) const observer = new IntersectionObserver((entries) => { entries.forEach(entry => { if (entry.isIntersecting) { anime({ targets: entry.target.querySelectorAll('.reveal'), translateY: [40, 0], opacity: [0, 1], duration: 800, delay: anime.stagger(80), easing: 'easeOutExpo' }); observer.unobserve(entry.target); } }); }, { threshold: 0.15 });
